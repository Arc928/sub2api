# Console fonts

These Latin subsets are served locally; Chinese and Japanese use system fonts.

- `inter-latin.woff2`: Inter variable, weights 400–700, from Google Fonts.
- `cormorant-garamond-latin-500.woff2`: Cormorant Garamond, weight 500, from Google Fonts.

Both are licensed under the SIL Open Font License 1.1. Their unmodified licenses
are included as `inter-OFL.txt` and `cormorantgaramond-OFL.txt`.

Sources: https://fonts.google.com/specimen/Inter and
https://fonts.google.com/specimen/Cormorant+Garamond (downloaded 2026-10-01).
